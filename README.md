# IAAC - Modelado, Simulación y Control de Sistemas Dinámicos 🚀

Este repositorio contiene una colección de prácticas y proyectos enfocados en el modelado matemático, simulación numérica y diseño de estrategias de control para sistemas dinámicos. Todos los trabajos aquí presentes forman parte de la evaluación de la asignatura, en la cual se obtuvo **la máxima calificación (10 - Matrícula de Honor)**.

Las implementaciones están desarrolladas principalmente utilizando **MATLAB** y **Simulink**, aplicando principios fundamentales de la teoría de control clásico, control avanzado e Inteligencia Artificial aplicada.

## 🛠️ Tecnologías y Herramientas
- **Lenguajes:** MATLAB, scripting
- **Herramientas de Simulación:** Simulink
- **Conceptos:** Dinámica de Sistemas, Controladores PID, Ziegler-Nichols, Control Difuso (Fuzzy Logic), Sistemas Expertos, Redes Neuronales Artificiales, Cinemática de Robots.

---

## 📂 Estructura del Repositorio

El proyecto se divide en 5 bloques prácticos (P1 a P5), cada uno enfocado en una rama específica del análisis de sistemas y control:

### 🔹 [P1] Procesamiento de Datos y Scripting Básico
- Manejo y transformación de conjuntos de datos numéricos (series temporales, temperaturas).
- Scripts base de MATLAB para la automatización de la lectura y limpieza de datos estructurados.

### 🔹 [P2] Modelado y Control Clásico en Simulink
- Diseño y simulación de lazos de control cerrados para plantas dinámicas.
- Implementación y sintonización paramétrica de controladores proporcionales e integrales (Control **P** y **PI**).
- Análisis de la respuesta temporal, estabilidad y mitigación de errores en régimen permanente.

### 🔹 [P3] Sistemas Expertos y Método Ziegler-Nichols
- Aplicación de métodos empíricos de sintonización (Ziegler-Nichols) para ajustes de bucles de control.
- Desarrollo de un sistema de control experto basado en reglas lógicas capaz de tomar decisiones de actuación sobre la planta simulada en tiempo real.

### 🔹 [P4] Controladores Lógicos Difusos (Fuzzy Logic)
- Diseño de sistemas de inferencia difusa aplicados al control de sistemas no lineales.
- Implementación de controladores PID-Fuzzy y su integración dentro de modelos visuales de Simulink.

### 🔹 [P5] Inteligencia Artificial y Cinemática
- **Redes Neuronales:** Entrenamiento y validación de Redes Neuronales Artificiales para el modelado predictivo o aproximación de funciones matemáticas complejas.
- **Cinemática Aplicada:** Modelado matemático del comportamiento espacial y movimientos de un brazo robótico, abarcando tanto cinemática directa como inversa.

---

## 🚀 Entorno de Simulación

El código y los modelos están diseñados para ser ejecutados de manera nativa en el entorno de MathWorks. Para probar o visualizar el comportamiento de las prácticas:

1. Requiere una instalación funcional de **MATLAB** con las toolboxes correspondientes (Control System Toolbox, Fuzzy Logic Toolbox, Deep Learning Toolbox).
2. Los scripts algorítmicos se ejecutan directamente desde el *Command Window* o editor integrado.
3. Los esquemas de control y plantas virtuales se visualizan y simulan inicializando **Simulink** sobre los archivos del proyecto.
